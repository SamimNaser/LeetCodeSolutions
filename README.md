# LeetCode Solutions

My Java solutions for LeetCode problems.

## Structure

Files are named by problem number:

```text
problem_1920.java
problem_771.java
problem_1108.java
```

Each file contains a standalone Java class with a small `main` method for local testing.

## Run Locally

Compile a solution:

```bash
javac problem_1920.java
```

Run it:

```bash
java problem_1920
```
